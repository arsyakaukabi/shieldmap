# Full headline table

*The full headline table is released as data; the manuscript prints only the numbers it quotes.*

- Files: `data/phase4d/headline_table_v4.csv` (every number of the manuscript: the rows of v3 plus H401 onwards) and
  `data/phase4b/headline_table_v3.csv`, in this repository and in the Zenodo data record (`10.5281/zenodo.23457298`) under the
  same paths.
- Generated by `src/shieldmap/analysis4d/table_v4.py` and `src/shieldmap/analysis4b/table_v3.py`.
- Rows: H-rows are headline values (prices, leaders, densities, Monte Carlo results, revision analyses); A01–A36 are
  headroom prices against the unconstrained artefact-free frontier F0 ([Headroom](headroom.md)).
- Columns used by the manuscript: `statement_v3` (full statement), `value` / `value_pct`, `band_lo_pct` / `band_hi_pct`
  (credible band; for prices: polymorph rules R1–R3 × frontier kinds × coherent scattering on/off), `delta_abs` and
  `delta_unit` (absolute increment), `mc_status` (status under the Monte Carlo spot check), `quoted_in` and
  `manuscript_id` (placement in the manuscript, rewritten by every build from `paper/build/number_usage.json`).
- Row identifiers are the source tags of the manuscript: every number in `paper/main.tex`, `paper/supplementary.tex` and
  `paper/tables/*.tex` carries its row in a LaTeX comment (rules in `paper/CONVENTIONS.md`), and `paper/check_numbers.py`
  verifies each printed number against this file.
- The first-order caveat printed with some statements is superseded by the per-family Monte Carlo under-counts
  of rows H242–H245 ([Fluorescence model](fluorescence_model.md)).
